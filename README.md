# viju · кнопка «Подключайся»

Живой прототип и handoff для iOS и Android.

**Открыть:** включите GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root) и откройте ссылку, которую покажет GitHub.
Страница закрыта паролем (спросите у Романа). Содержимое в репозитории зашифровано.

Финальное решение:
- Главная, кнопка в шапке — эффект «Кромка», раз в 4 с.
- Пейвол, большая кнопка — эффект «Импульс», раз в 4 с (почти непрерывно).

Всё для вёрстки — в прототипе, кнопка **«Для разработки»**: значения, тайминги, код SwiftUI и Jetpack Compose (эффекты, кнопки целиком, нажатие, переход на пейвол), чек-лист приёмки и частые вопросы. Переключатель iOS / Android — вверху справа, «Скопировать ТЗ» собирает всё одним текстом.
